# AgriFlow — Agricultural Marketplace & Management Platform

https://adam-radi.vercel.app

**AgriFlow** is a full-stack agricultural marketplace and management platform designed to connect farmers, customers and delivery users through a modern web application.

The project focuses on managing agricultural products, harvests, orders, deliveries and user roles through a structured Laravel backend.

## Project Overview

AgriFlow provides a digital platform for agricultural commerce and farm-related operations.

The application is designed around multiple user roles:

- Customer
- Farmer
- Delivery
- Administrator

The platform supports agricultural product management, orders, deliveries and administrative workflows.

## Key Features

- User authentication and authorization

- Agricultural product management
- Farmer management
- Customer management

- REST API architecture
